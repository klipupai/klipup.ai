Yes — that's a GitHub Pages 404, and it's exactly the filename issue.

Fix it in 30 seconds:

Your file is currently named Index.html with a capital I. GitHub Pages is case-sensitive and for the root URL it must be lowercase index.html.

Do this:

  1. Go to your GitHub repo → click on Index.html
  2. Click the pencil ✏️ to edit / or click ... → Rename
  3. Rename it to exactly: index.html (all lowercase)
  4. Commit it
  5. Wait 30 sec and refresh your domain — the 404 will be gone

Also check these two things:

  • The file must be at the root of the repo, not inside a folder like /site/ or /docs/ — if it's inside a folder, move it to the root
  • In GitHub → Settings → Pages, make sure it's set to:
    • Branch: main
    • Folder: / (root)

If you already renamed it and still see 404, wait 1-2 minutes — GitHub Pages takes a minute to redeploy. Or hard refresh Ctrl + Shift + R.

When they fill the Discovery form, this is what happens — in 3 steps:

Step 1 — Form (1 of 3):
They enter: First name, Last name, Email, Company, Industry, Company size, Package, Budget, Current Challenge, How soon to start, How they heard about you.

On submit, the site does a POST with all that data as JSON to your webhook:
https://script.google.com/macros/s/AKfycbzP.../exec — that's a Google Apps Script. That script is what saves it to your Google Sheet / emails you.

If it succeeds:

"Thanks. Your discovery details were sent successfully. Continue to Step 2 to book on Calendly."[Name]

If it fails (webhook down):

"Your discovery details are ready for scheduling. The discovery service could not be reached, but you can still continue to Step 2 to book on Calendly."
— It still lets them continue, it doesn't block them.

Step 2 — Discovery Scheduling (2 of 3):
It moves them to the Calendly embed:
calendly.com/founders-klipup/30min
They book the 30-min call there.

Step 3 — Payment (3 of 3):
Then it shows the Stripe payment link for the package they chose:

  • Product Team: $3k/mo
  • Growth Team: $3k/mo
  • Startup Team: $8k/mo

So: Form → Google Sheet / email to you → Calendly booking → Stripe payment.
